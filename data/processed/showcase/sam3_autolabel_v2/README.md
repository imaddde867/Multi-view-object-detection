# Labeling Showcase (viz-only)

This folder contains a small, curated subset of visualization frames plus metadata
from the SAM3 autolabeling run. It is intended for presentation and review, not
for training or verification.

Included:
- `viz/` sample frames with overlaid boxes/masks
- `meta.json`, `stats.json`, `dataset.yaml` for provenance

Full training datasets remain outside git.
